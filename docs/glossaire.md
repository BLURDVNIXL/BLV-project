# Glossaire

* **Jalon** : un des 6 moments communs (0 foyer, 1 ombres du chantier, 2 alliances, 3 crue, 4 grand déballage, 5 première pierre).
* **Carrefour** : A (Rue Princesse, jour 110), B (crue, jour 281), C (descente, jour 283).
* **Compromission** : score -10..+10 mesurant l'implication dans des actes ou alliances compromis (ex-« curseur Lumière/Ombre »).
* **Étoile** : chance contextuelle 0–100 ; module les tirages, jamais une garantie.
* **Tirage** : choix à issues (miracle, normal, mauvaise) ; chaque issue a ses effets et sa destination.
* **Porte** : nœud (`porte: true`) par lequel un métier illégal peut être proposé.
* **Preuve** : objet de dossier avec cycle de vie (détenue → transmise → contestée / perdue).
* **Fait relationnel** : événement mémorisé dans une relation (`relations.x.faits.y`) en plus des jauges.
* **Fin imposée** : fin (en pratique tragique) qui s'applique seule quand sa chaîne causale est réunie.
* **Événement différé** : retombée ou action d'un secondaire, datée ou planifiée, exécutée une seule fois.
